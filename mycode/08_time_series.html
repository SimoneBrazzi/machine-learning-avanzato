Stationarity

Stationarity when statistical properties (mean, variance, autocorrelation) are constant during time. - Low

  • \(E[X_t] = \mu,\ \forall t\) -> constant mean.

  • \(Var[X_t] = \sigmaˆ2,\ \forall t\) -> constant var.

  • \(Cov(X_t, X_{t+h}) = \gamma (h), \forall t,\ h\) -> autocovar depends only by h, the lag.

  • Strong -> join distribution \(X_{t_1}, X_{t_2}, ... X_{t_n}\) invariant to traslation over time.

Why it is so important?

  • Predictive modelling, for example with ARIMA, because this type of model assumes a stable data generation.

  • Transformation techniques, like differentiation, trend removal, log transformations.

How to?

  1. Visualize data to understand if there is stationarity or not.

  2. Transformations:

  • Diff.

    • Simple diff: \(y'_t = y_t - t_{t-1}\) .
    • Seasonal diff: \(y'_t = y_t - y_{t-s}\)

  • BoxCox transformation.

    \[ y(\lambda) = \begin{cases} \frac{yˆ{\lambda} - 1}{\lambda},\ if \lambda \neq 0;\\ \log y,\ if \lambda = 0. \end{cases} \]

  • Detrend: estimate and removal of the series trend.

  1. Stationarety statistical test

  • Augmented Dickey-Fuller: \(\Delta Y_t = \alpha + \beta t + \gamma Y_{t-1} + \sum_{i=1}^{p} \delta_i \Delta Y_{t-i} + \epsilon_t\), where reject \(H_0\) : not stationary if p < 0.05.

    • Kwiatkowski-Philips-Schidt-Shin: \(Y_t = \mu + r_t + \epsilon_t\), where \(r_t\) is a random walk.

Forecasting

Classic model

AR model

Auto Regressive model AR(p). It is a regression on itself.

\(y_t = c + \sum_{i=1}^{p} \theta y_{t-i} + \epsilon_t\)

\(\theta\): autoregressive coeficcients. p: number of lagged elements. \(\epsilon_t\): causal error at time t. c: intercept.

MA model

Moving Average. Value at time t linearly dependent to previous forecasting errors.

\(y_t = c + \sum_{i=1}^_{q} \theta_{i}\epsilon_{t-i}\)

\(\theta_i\): moving avg coefficients. q: n lagged elements for MA. \(\ epsilon_t\): causal errors at time t. c: intercept.

ACF and PACF

The selection of the parameters p and q depends on this models.

AR model

  • PACF: where data are 0.
  • ACF: decay to 0 esponentially or sinusoidally.

MA model

  • ACF: where data are 0.
  • PACF: decay to 0 esponentially or sinusoidally.

ARMA model

  • Both plots decay.
  • First lag on ACF depend on q from the MA model. After q, ACF decayment.
  • First p lag on PACF depend on AR model. After p, PACF decay.

ARIMA

Auto Regressive Integrated Moving Average. Useful for non stationary data. It adds differentiation.

\(y'_t = c + \sum_{i=1}_{q} \theta_i y'_{t-i} + \epsilon_t\)

  • p: order of the autoregressive componenet.
  • d: order of differentiation. Times of diff needed for stationarety.
  • q: order of the moving avg component.

It uses ACF, PACF and also:

AIC

Akaike Information Criterion.

\(AIC = 2\log(L) + 2(p + q + k + 1)\)

BIC

Bayesian Information Criterion.

\(BIC = AIC + [\log(T) - 2](p + q + k + 1)\)

SARIMA

Seasonal ARIMA. It extend the ARIMA model to non stationary situations.

SARIMA(p, q, d)(P, Q, D, s)

  • p, non seasonal component order.
  • P, seasonal component order. …
  • s, seaonality period.

\((1 - \theta B)(1 - \Sigma B^4)(1 - B)( 1 - Bˆ4)y_t = (1 + \Theta B)(1 + \Theta Bˆ4)\ epsilon_t\)

def adf_test(x):

  result = adfuller(x)

  else:

  return result

Seasonal AutoRegressive Integrated Moving Average.

\(SARIMA(p, d, q)(P, D, Q, s)\), where:

  • p = autoregressive order.
  • d = number of non-seasonal differences. n of regular differences applied to make it stationary.
  • q = moving average order.
  • P = seasonal autoregressive order.
  • D = seasonal differencing order. n of seasonal differences.
  • Q = seasonal movin average order.
  • s = length of the seasonal period. Eg.: 12 for monthly data.

It is important to remove seasonality with seasonal differencing to make data stationary.

\[ (1 - \phi_1 B)(1 - \Phi_1 B^s)(1 - B)(1 - B^s)y_t = (1 + \theta_1 B)(1 + \Theta_1 B^s)\epsilon_t \]

\(y_t\) = observed time series at time t. B = backshift operator or lag. \(\phi_1\) = non-seasonal autoregressive coefficient. \(\Phi_1\) = seasonal autoregresive coefficient. \(\theta_1\) = non-seasonal moving average coefficient. \(\Theta_1\) = seasonal moving average coefficient. s = seasonal period. \(\epsilon_t\) = white noise error term.

ACF measures the correlation between the time series and its lagged values.

  • AR if decays gradually.
  • MA if cuts off sharply.

PACF measures the correlation between the timne series and its lagged values, * controlling* for the correlations at intermediate lags.

  • AR if cuts off sharply.

  • MA if decays gradually.

  • non seasonal -> p, d, q.

  • seasonal = P, D, Q, s. d and D depends on the number of differentiation I had to do to make the serie stationary. s depends on the data: for monthly data, 12. number of NON SEASONAL components (1,2,3, …): q depends on ACF. p depends on PACF. number of SEASONAL components (12, 24, …): Q depends on ACF P depends on PACF

ML and DL for Time Series

RNN

Recurrent Neural Network are useful with sequential data. It uses the concept of memory, meaning the previous information is used in the next steps. Hidden state makes possible the information sharing between layers. There is a problem: vanishing gradient, meaning the gradient tends to be smaller the longer the NN. This slows down the computation. LSTM and GRU help to solve this problem. Long Short Term Memory, a type of RNN useful for time series.

  • Cell state preserve the memory.
  • Gates, input door (input, forget and output) to manage the information flow and let the model save and drop informations.

Gated Recurrent Unit, a simplified LSTM which binds forget and input in a single gate to improve computational performance.

Convulutional Neural Network can be used for time series analysis. Good for local dependencies, bad on the long term one. Useful in combination with previous one.

Prophet

Addictive model for time series with a strong seasonal, holiday and trend shift.

\(y(t) = g(t) + s(t) + h(t) + \epsilon_t\)

  • g(t) = trend.
  • s(t) = seasonality.
  • h(t) = holidays.
  • \(\epsilon_t\) = residual noise.

Pro

  • outlier and missing values handling.
  • robust.
  • quick training.
  • automatically find seasonality.

Cons

  • Less flexibility.
  • Addictive model does not work well with multiplicative data, for example for variance.

Accuracy

Mean Absolute Error: \(MAE = \frac{1}{n} \sum_{i=1}^{n} |Y_i - \hat{Y_i}|\)

  • avg absolute error -> precision.
  • robust to outlier.

Root MSE: \(RMSE = \sqrt{ \frac{1}{n} \sum_{i=1}^{n} (Y_i - \hat{Y_i})^2 }\)

  • better penality for big errors.

Mean Absolute Percentage Error: \(MAPE = \frac{100}{n} \sum_{i=1}^{n} \left| \frac{Y_i - \hat{Y_i}}{Y_i} \right|\)

  • Mean of the percentage errors.
  • It does not depends on the data scale.
